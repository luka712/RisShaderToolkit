# Changelog

## [0.2.2] - 2026-04-02

### Fixed
- Linux crashes.

## [0.2.1] - 2026-03-21

### Fixed 
- Exception which occurs on Windows when compiling to `glsl` shaders.

## [0.2.0] - 2026-03-21

### Added
- `Slang` to `glsl` shader compilation is now supported.
- `CompileSlangToGlsl` method was added to the `ShaderCompiler`.

## [0.1.0] - 2026-03-04

### Added
- `ShaderCompiler` with `CompileSlangToWgsl` and `CompileSlangToSpirV` methods.
